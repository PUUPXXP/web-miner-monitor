# 采集端使用说明（Windows）

采集端（`agent/`）是跑在每台矿机上的小程序：读取显卡状态、管理矿工进程、执行控制台下发的命令。
它没有任何第三方依赖，只需要 **Node.js ≥ 22.5**，**同一套代码同时支持 Windows 与 Linux**。

- Windows：按本文第 1 节安装（计划任务开机自启）
- Linux / MinerOS：见第 8 节（systemd 管理，或直接用烧好的 MinerOS U 盘）

---

## 1. 安装

### 方式 A：一条命令（推荐）

到控制台「矿机 → 添加矿机」创建矿机，弹窗里会给出专属安装脚本（含密钥）。在矿机上：

1. 开始菜单搜索 **PowerShell** → 右键 **以管理员身份运行**
2. 粘贴脚本回车

脚本会：

| 步骤 | 动作 |
|---|---|
| 1 | 检查 Node.js，未安装则从 nodejs.org 下载 LTS 并静默安装 |
| 2 | 从控制台下载采集端到 `C:\ProgramData\MinerMonitor` |
| 3 | 写入 `config.json`（含服务器地址、矿机密钥、名称） |
| 4 | 注册计划任务 `MinerMonitorAgent`（SYSTEM、开机自启、失败重试）并启动 |

安装完成后约 10 秒，控制台就能看到这台矿机在线。

### 方式 B：手动部署

```powershell
# 1. 拷贝项目里的 agent/ 和 shared/ 到矿机，例如 C:\MinerMonitor
# 2. 创建 config.json
@'
{
  "serverUrl": "http://192.168.1.10:8787",
  "token": "rig_你的密钥",
  "rigId": "矿机ID",
  "name": "矿机名",
  "intervalSec": 5
}
'@ | Set-Content C:\MinerMonitor\config.json -Encoding UTF8

# 3. 前台运行（调试）
node C:\MinerMonitor\agent\agent.js --config C:\MinerMonitor\config.json

# 4. 注册计划任务（开机自启）
$node = (Get-Command node).Source
$action = New-ScheduledTaskAction -Execute $node -Argument '"C:\MinerMonitor\agent\agent.js" --config "C:\MinerMonitor\config.json"' -WorkingDirectory 'C:\MinerMonitor'
$trigger = New-ScheduledTaskTrigger -AtStartup
$settings = New-ScheduledTaskSettingsSet -RestartCount 999 -RestartInterval (New-TimeSpan -Minutes 1) -ExecutionTimeLimit (New-TimeSpan -Seconds 0)
Register-ScheduledTask -TaskName MinerMonitorAgent -Action $action -Trigger $trigger -Settings $settings -User SYSTEM -RunLevel Highest -Force
Start-ScheduledTask MinerMonitorAgent
```

### 方式 C：自动注册（不填密钥）

控制台「设置 → 采集端 → 允许采集端自动注册」开启后，矿机上直接运行：

```powershell
node agent\agent.js --config config.json
```

只要 `config.json` 里没有 `token`，采集端会带机器指纹向服务器注册，自动出现在「待分组」。

## 2. 配置项

| 字段 | 默认 | 说明 |
|---|---|---|
| `serverUrl` | — | 控制台地址，例如 `http://192.168.1.10:8787` |
| `token` | — | 矿机密钥（安装脚本写入） |
| `rigId` | — | 矿机 ID（安装脚本写入） |
| `name` | 主机名 | 显示名称（服务器端可改） |
| `workDir` | 采集端目录 | 日志、矿工日志、状态文件存放位置 |
| `intervalSec` | `5` | 心跳间隔，服务器可下发覆盖 |
| `allowReboot` | `true` | 是否允许远程重启/关机 |
| `allowRun` | `true` | 是否允许执行自定义 PowerShell |
| `allowUpdate` | `false` | 是否允许远程自更新（默认关闭，建议用安装脚本升级） |
| `minerPath` | — | 矿工根目录（可选，覆盖默认 `workDir/miners`） |

也可以全部用环境变量：`MM_SERVER`、`MM_TOKEN`、`MM_RIG_ID`、`MM_WORK_DIR`、`MM_INTERVAL`。

---

## 3. 矿工放置

采集端默认在以下位置找矿工：

```
<workDir>\miners\<矿工ID>\<可执行文件>
例：C:\ProgramData\MinerMonitor\miners\xmrig\xmrig.exe
    C:\ProgramData\MinerMonitor\miners\peakminer\peakminer.exe
```

- 用 `scripts/miner-download.ps1` 可以自动下载并放好：

```powershell
.\miner-download.ps1 -Dest "C:\ProgramData\MinerMonitor\miners" -Miner xmrig,peakminer
```

- 也可以放在任意路径，在飞行表的「矿工路径（可选）」里填**绝对路径**。
- 矿工需要**自己先能跑通**：手动执行一次，确认能连上矿池、看到算力，再接采集端。

---

## 4. 采集端做什么

每 `intervalSec` 秒（默认 5 秒）：

1. **拉命令**：`POST /api/agent/commands`，有命令就执行并回传结果
2. **采集 GPU**：`nvidia-smi`（NVIDIA）/ 性能计数器（AMD）
3. **刷新矿工**：确认进程存活、请求矿工 API、必要时解析日志
4. **看门狗**：崩溃重启、算力骤降重启、过热停机
5. **上报遥测**：`POST /api/agent/heartbeat`，带上配置哈希，配置变了自动重启矿工

启动时若飞行表 `autoStart=true` 且矿机未被禁用/维护，会自动拉起矿工。

### 看门狗行为

| 情况 | 动作 |
|---|---|
| 矿工进程退出 | 等 `restartDelaySec`（默认 10s）后自动重启，1 小时内超过 20 次则暂停（防止死循环） |
| 算力为 0 或较基线下降超过阈值（默认 60%） | 重启矿工（启动 3 分钟后才判断，避免预热误判） |
| 最高温度 ≥ 阈值（默认 85°C）持续 30 秒 | 停止矿工保护硬件 |
| 重启后 | 事件写入控制台「事件日志」，累计次数显示在矿机卡片 |

## 5. 常用命令

```powershell
# 自检：GPU 接口、系统信息、矿工进程、服务器连通性、注册状态
node agent\agent.js --check

# 单次上报（联调用）
node agent\agent.js --once

# 无显卡时模拟上报（2 张假 GPU）
node agent\agent.js --simulate --gpus 2 --once

# 前台调试运行（Ctrl+C 退出，会同时停止它启动的矿工）
node agent\agent.js --config C:\ProgramData\MinerMonitor\config.json
```

### 计划任务管理

```powershell
Get-ScheduledTask MinerMonitorAgent | Get-ScheduledTaskInfo     # 查看状态
Start-ScheduledTask MinerMonitorAgent                          # 启动
Stop-ScheduledTask MinerMonitorAgent                           # 停止
Get-Content C:\ProgramData\MinerMonitor\logs\agent.log -Tail 50 # 日志
Unregister-ScheduledTask MinerMonitorAgent -Confirm:$false       # 卸载（不会删文件）
Remove-Item -Recurse C:\ProgramData\MinerMonitor                # 删目录
```

## 6. 排错

| 现象 | 排查 |
|---|---|
| 控制台看不到矿机 | 矿机上 `node agent\agent.js --check`；检查 `serverUrl` 是否可从矿机访问（`Test-NetConnection <IP> -Port 8787`）；防火墙放行 8787 |
| `--check` 显示「密钥无效」 | 在控制台矿机详情页重置密钥并重新执行安装脚本；或开启自动注册 |
| GPU 为空 | 矿机上运行 `nvidia-smi` 是否正常；AMD 卡只有部分指标 |
| 矿工不启动 | 看 `logs\miner\miner.log`；确认 `miners\<ID>\<exe>` 存在；飞行表是否分配、矿机是否启用 |
| 矿工启动后立刻退出 | 手动运行 miner.exe 看报错（缺少 VC++ 运行库、驱动版本过低、钱包/矿池参数错误） |
| 命令没执行 | 命令会排队，矿机上线后自动下发；在「事件日志」查看命令结果 |
| 温度/风扇显示 `—` | nvidia-smi 对该卡返回 `[N/A]`（笔记本/虚拟机常见） |
| 时间不对 | 矿机与服务器时间差过大会影响心跳判断，开启 Windows 自动对时 |

日志位置：

- 采集端：`<workDir>\logs\agent.log`
- 矿工输出：`<workDir>\logs\miner\miner.log`
- 服务端：`data\logs\server.log`

## 7. Linux / MinerOS 上的采集端

### 用 MinerOS U 盘（推荐）

烧好 MinerOS 后插入矿机开机，采集端已内置并由 systemd 启动，无需手动安装：

- 配置：`/etc/mineros/agent.json`（首次启动由 U 盘 `rig.conf` 生成）
- 服务：`mineros-agent.service`（崩溃自动重启）
- 日志：`journalctl -u mineros-agent -f`、`/var/lib/mineros/logs/`
- 状态：屏幕 tty1 面板，或浏览器 `http://<IP>:4000`
- 矿工：放 `/opt/mineros/miners/<矿工ID>/<可执行文件>`，或在飞行表填绝对路径

详见 [MinerOS镜像说明.md](MinerOS镜像说明.md)。

### 已有 Linux 系统上手动安装

```bash
# 1. 安装 Node.js 22.5+（需要 node:sqlite）
#    Debian/Ubuntu 可用 NodeSource，或直接解压官方 linux-x64 包
sudo mkdir -p /opt/mineros /etc/mineros /var/lib/mineros
sudo cp -a agent shared /opt/mineros/
sudo cp -a /path/to/node /opt/mineros/node   # 或系统 node 在 PATH 中

# 2. 写配置
sudo tee /etc/mineros/agent.json >/dev/null <<'EOF'
{
  "serverUrl": "http://192.168.1.10:8787",
  "token": "rig_xxx",
  "rigId": "xxx",
  "name": "linux-rig-01",
  "workDir": "/var/lib/mineros",
  "minerPath": "/opt/mineros/miners",
  "intervalSec": 5,
  "allowReboot": true,
  "allowRun": true
}
EOF

# 3. systemd 服务
sudo tee /etc/systemd/system/mineros-agent.service >/dev/null <<'EOF'
[Unit]
Description=MinerOS Agent
After=network-online.target
Wants=network-online.target
StartLimitIntervalSec=0

[Service]
Type=simple
User=root
WorkingDirectory=/opt/mineros
Environment=MM_CONFIG=/etc/mineros/agent.json
Environment=MM_WORK_DIR=/var/lib/mineros
Environment=PATH=/opt/mineros/node/bin:/usr/local/bin:/usr/bin:/bin
ExecStart=/opt/mineros/node/bin/node /opt/mineros/agent/agent.js --config /etc/mineros/agent.json
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload
sudo systemctl enable --now mineros-agent

# 4. 自检
/opt/mineros/node/bin/node /opt/mineros/agent/agent.js --check
```

### Linux 差异说明

| 能力 | Windows | Linux |
|---|---|---|
| 进程结束 | `taskkill /T /F` | 先 SIGTERM，1.2 秒后 SIGKILL（含进程组） |
| 进程识别 | PowerShell CIM | `/proc/*/cmdline` |
| NVIDIA 监控 | nvidia-smi | nvidia-smi（相同） |
| AMD 监控 | 性能计数器（仅利用率/显存） | amdgpu sysfs（温度/风扇/功耗/显存/核心频率） |
| CPU 温度 | 无 | hwmon（k10temp/coretemp/zenpower） |
| 系统信息 | PowerShell + wmic | `/proc`（cpuinfo/meminfo/stat/uptime）+ `df` |
| 关机/重启 | `shutdown` | `systemctl reboot/poweroff` |
| 自定义命令 | PowerShell | `sh -c` |
| 超频 | nvidia-smi -pl/-lgc/-lmc/-fs | nvidia-smi -pl/-lgc；风扇/显存需 X + nvidia-settings（无 X 时跳过） |
| 开机自启 | 计划任务 | systemd |

## 8. 安全

- 采集端以 **SYSTEM** 运行：可以重启机器、改 `nvidia-smi` 功耗墙、杀掉矿工。请确保服务器本身可信。
- 不想要远程重启/关机：`config.json` 里 `"allowReboot": false`。
- 不想要远程执行任意命令：`"allowRun": false`。
- 矿机密钥等同于该矿机的登录凭据，泄露后在控制台重置即可作废旧密钥。
- 建议把控制台放在内网/VPN 后，或使用反向代理 + HTTPS。
- Linux / MinerOS 上采集端以 root 运行（远程重启、nvidia-smi 改功耗墙需要）；本地控制台 :4000 无鉴权，仅限内网访问。
